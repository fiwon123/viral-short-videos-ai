# Memory templates

Working memory lets a new or interrupted session resume without guessing. Studio memory is [ROADMAP.md](ROADMAP.md), which is tracked and generic. Channel and episode memory live under the ignored `workspace/` folder. Copy these templates there and keep them short and current.

## `workspace/<slug>/MEMORY.md` (channel)

```markdown
# <Channel name>: working memory

Updated: YYYY-MM-DD

## Now
- Current focus: <episode or task>
- Next step: <exact action or command>

## Decisions that stand
- Format, length, platform:
- Look and art technique:
- Voice cast and caption preset:
- Sound: sample packs imported, signature cues:

## Open issues
- 

## Where things are
- Rules: channel/AGENTS.md
- Episodes made, in progress and planned: channel/episode-ledger.md
- Brief and brand: channel/brief.md, channel/channel.md
- Latest renders: renders/
```

## `workspace/<slug>/channel/AGENTS.md` (channel rules)

Write the rules that hold for every episode here: tone, story rules, visual and sound identity, and what to avoid repeating.
