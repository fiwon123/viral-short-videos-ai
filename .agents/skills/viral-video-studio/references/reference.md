# Reference breakdown

## Select comparable examples

For a channel's most-viewed Shorts, start with its YouTube Shorts tab sorted by **Popular**. Record the retrieval date, rank, title, direct URL, displayed lifetime views, and duration. If using an index or an optional analytics integration, record the source and qualify rankings as the highest among its indexed uploads. Use dated view history or a same-age cohort of the channel's comparable uploads when the question concerns recent breakout performance. For a broad style study, include 2D, layered or mixed 2D/3D, and full 3D. Label supporting films, clips, and making-of videos so they serve as craft references when comparing Shorts performance.

## Inspect the material

With an authorized local media file, run `python3 video.py analyze reference-media/source.mp4 --out output/<name>-reference`. Add `--focus-shorts` to sample the first and last two seconds more closely. Review the contact sheet, individual frames, candidate cut times, and extracted audio. Use embedded captions if present. Use available audio transcription or listen to verify lines and pacing. For links, use the public player, captions, and any available creator production notes. If playback or audio is inaccessible and a full breakdown depends on it, request an authorized local file and complete the supported part.

Group timecoded observations into scenes and shots. Verify cut candidates on both sides, including changes caused by overlays, reframing, and fast motion. Note opening and closing composition, object positions, camera or subject movement, on-screen text, speech timing, sound and music changes, and transition. Separate observed behavior from inferred tools, source assets, and performance causes. Identify the hook, setup, escalation, payoff, and exit. Give the user a short list of techniques to carry into original episodes.

For a multi-video study, save one row per video in `research/`. Note which evidence supports each observation. Player stills can support composition, pose, and visible text. Use continuous playback for exact pacing, camera movement, loops, and sound cues. Use credited production notes for pipeline claims. Leave any unavailable evidence unknown.
