# Episode production

## Write for the channel

Use the saved brand and reference research. Start vector-led 2D or 2.5D episodes with HyperFrames and GSAP-driven SVG layers. Choose where 3D adds useful perspective or motion. Open the approved character references and load recurring sets before drafting shots. Use the [staging and visual QA guide](visual-qa.md) to lock layer order, object contacts, and lighting. Follow the [renderer guide](renderers.md) for layer order and asset reuse. Define format, target length, audience, language, and voice. Select a platform-appropriate canvas and keep graphics, captions, and character actions clear of platform overlays. Establish the hook quickly, build a visual sequence that changes with each beat, and pay off the title and thumbnail promise. Check any factual claims with authoritative sources. Use original visuals and licensed or authorized assets.

For original Shorts, use the [Shorts animatic and shot planning guide](shorts.md) before full production. Use the chosen story beats to set the runtime, verify the opening and payoff in a rough phone-size playback, and resolve any shot that depends on mixing 2D with 3D.

Write the episode under `workspace/<channel>/episodes/<episode>/episode.json` (or `episodes/<slug>/episode.json` for a legacy project) using the `episode` definition in the [schema](../../../../studio/schema.json). Set `max_seconds` when the user's or platform's hard limit is below 720 seconds. Store imported assets alongside the manifest. Use small storyboard previews when they help resolve composition. Use the `direction` field to describe character action, expression, camera framing, environment, and sound or transition intentions. Translate each instruction into visible layers, keyframes, audio cues, or imported graphics. Use distinct scene, shot, and layer IDs so the rendered timeline can be compared to the source. Apply a `style.preset` for a coherent first pass, then override only what the story needs.

## Approve the soundtrack

Load the versioned channel cast and sound bank. Follow the [audio guide](audio.md) to direct recurring character voices, choose action-specific Foley, and review a WAV with `video.py audio` before locking visual timing. Use measured takes for captions, mouth motion, and reaction holds.

## Animate and align

- Layer order is back to front within each plane. Position is the center of each layer, in fractions of the canvas with top left as the origin. Layer width and height are fractions of the canvas. Images and SVGs fit inside their boxes with the source aspect ratio. Shapes, text, and keyframes can be combined for custom characters, staging, graphics, and simulated camera movement. Coordinate the movement of all affected layers when staging a camera move.
- Keyframe `at` runs from 0 to 1 across the **resolved** shot. It inherits values from the previous pose. The easing on a keyframe describes motion arriving at that pose. Use keyframes for entrances, exits, effects, movement, and holds. `dissolve` and `wipe-left` reveal the incoming shot over the outgoing shot's final clean frame within the incoming shot's duration.
- Speech and sound cue offsets are seconds from shot start. Omit a speech offset to follow the previous take after a short pause. Split speech into short clauses to keep each caption readable. A recorded or generated file may replace any line. Use an explicit `caption` for translated or display-edited subtitles. The tool trims quiet edges, measures the take, fits the shot if needed, and writes a caption timed to that clip. The `mouth_for` field drives simple audio-level motion for a speaker. Use assets or another animation engine for phoneme-accurate lip sync or advanced character rigs.
- Use channel sound variants or episode-specific effects and an optional music bed. The mixer ducks the bed under speech, places cues with `pan` and `reverb`, supports layered `sfx.layers`, and masters to −14 LUFS by default. Inspect loop joins. Treat legacy eSpeak and generic synth effects as scratch audio unless the user wants that sound.
- Use `camera` presets or keys, layer `pivot`/`parent`, `visible`/`variant_group`, `blend`, `blur` and shot `post` for the finish. Add `motion_blur` only after the timing is locked, and use `supersample: 2` for a clean master when render time allows. `captions.style: "karaoke"` uses the word timings the audio pass already writes. Use `render` to set CRF, preset, tune, audio bitrate and output switches; use `--no-captions`, `--no-thumbnail` and `--no-publishing` for review cuts.
- Create new audio with Sound Lab (`python video.py sound`) and new palette-matched effects with Effect Lab (`python video.py effect`) when the channel bank has no suitable cue or shape. Keep generated files inside the channel.

## Run and deliver

Run `validate` and `check-visual` for the declared shot checks, then render a small preview with `--preview` when it aids inspection. Check the full preview for clear narrative beats, legible and well-placed text, continuity, intentional sound, pronunciation, and speech/caption sync. Fix the inputs, then run the full-size render. Let the tool choose `output/<channel-slug>/<episode-slug>-v1` from the selected channel and episode folders. For revisions or source archives, keep the same channel folder and choose a fresh package name. Use FFprobe QA from the tool and inspect final frames, transitions, caption cues, and audio. Open the rendered thumbnail at feed size. Adjust the cover frame, copy, or assets if needed. Use `thumbnail.hide_layers` to omit on-screen headlines or overlays from the thumbnail only. Verify upload specifications for the chosen destination. Report any playback or listening checks you could not complete.

Give the user the MP4, SRT when there is speech, thumbnail, title, description, tags, and timed script. The render writes all copy into `publishing.md` beside `publishing.json`: a YouTube section with the title, description, and tags as separate copy blocks with character counts, and a TikTok section with a caption where the hashtags live inline because TikTok has no tags field. Read those blocks before delivering, replace a weak derived TikTok hook by setting `tiktok.caption` in the episode, and treat any over-limit marker as blocking. Close the reply with the absolute path of each file, MP4 first, then thumbnail, captions, `publishing.md`, and the editable manifests, and say which fields go where on each platform. Link the editable manifests and source assets so any assistant can continue. Include credits and asset licensing information when needed. For an external renderer, preserve this delivery package and verify the final timeline, encoded runtime, and captions against the master.
