# 💡 Find Ideas

The goal is not “a viral idea”. The goal is a **repeatable format** that gives the audience the same pleasure in a new situation.

## 1. Research the format, not the joke

Ask the AI:

```text
Find 5 original animated Shorts channels in [niche] for [country/language].
For each: strongest recent Short, link, date, views if verified,
runtime, hook, visible change, payoff, camera language and sound idea.
Separate observed facts from your hypotheses.
Do not copy their characters, jokes or scripts.
```

Save the notes under `workspace/<channel>/research/`.

Look for:

- The same promise across uploads
- A recognizable character silhouette
- A repeatable visual constraint
- A clear opening question
- A payoff that reads muted
- A loop or last-frame button

## 2. Build a series bible

Write one page with:

| Field | Example |
| --- | --- |
| Audience | “Phone-first viewers who like quiet visual comedy” |
| Promise | “A paper crane delivers one impossible letter” |
| Character | “Nearsighted, determined, easily distracted” |
| World | “Paper hills, one sun, a very long wind” |
| Format | “One delivery, three beats, 20–35 seconds” |
| Constraint | “The crane never speaks; only the narrator does” |
| Payoff patterns | “Wrong recipient, long delay, tiny miracle” |
| Visual signature | “Warm paper, thick ink, one orange accent” |

## 3. Generate 30 ideas, then filter

Use constraints:

```text
Generate 30 episode ideas for this channel.
Each idea: title, one-sentence hook, visible change, payoff,
and the one prop or camera move that makes it visual.
No dialogue-first ideas. No two ideas may use the same payoff.
```

Score each idea 1–5:

| Test | Question |
| --- | --- |
| Hook | Does the title/first frame raise one question? |
| Visual | Can it work muted? |
| Change | Does something visible change? |
| Payoff | Does it pay off the hook, not a different joke? |
| Loop | Can the last frame lead back to the first? |
| Effort | Can the AI render it with the channel’s assets? |
| Repeatable | Is it a new situation, not the same joke again? |

Keep the ideas that score 4+ on Hook, Visual and Payoff.

## 4. Use a mini beat sheet

Before writing a manifest:

```text
Hook: [what the viewer sees in the first second]
Question: [what they want to know]
Setup: [the one line of context]
Escalation: [two visible changes]
Payoff: [the answer to the question]
Loop: [the last frame that leads back]
```

If you cannot fill every row, the idea is not ready.

## 5. Start with the poster frame

Describe the frame that would make someone stop scrolling:

```text
Describe the poster frame: character position, prop, eyeline,
background, light, caption and the one thing that is about to change.
```

If the poster frame is boring, the Short will probably be boring.

## 6. Test the idea before production

- Read the hook aloud in one breath.
- Draw the poster frame as a thumbnail.
- Describe the payoff to someone without explaining the setup.
- Ask: “Would this still be funny/interesting muted?”
- Ask: “Is this a new situation for this character?”

## 7. Series patterns that scale

| Pattern | Example |
| --- | --- |
| Wrong recipient | A message reaches the wrong character |
| Escalating obstacle | Each attempt makes the problem bigger |
| Misunderstood instruction | A literal reading of a human phrase |
| One object, many uses | A single prop solves three problems |
| Rule of three | Two failures, one surprising success |
| Loop | The ending creates the beginning |
